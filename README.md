# Hardus Plumbing - Burst Pipe Repair Nationwide Platform

Production nationwide lead-generation and programmatic SEO platform for 24/7 emergency burst pipe repair services covering all 50 US States + DC and 30,909 cities.

## Key Architecture & Features
- **URL Structure**: Maximum 3-tier clean hierarchy (`domain.com/[state]/[city]/`) matching best-practice reference architecture.
- **Complete Nationwide Coverage**: 50 States + DC and 30,909 municipal city pages compiled with unique localized data.
- **Conversion-Optimized Hero**: Emergency call CTA routing to 24/7 hotline `(855) 499-4130`, rapid response badge, and high-impact media frame.
- **Topical Authority**: Comprehensive emergency survival protocols, detailed 2026 cost matrix by state with regional cost disclaimer, and localized FAQs.
- **Technical SEO & Schema**:
  - Full JSON-LD schema graphs (`Organization`, `WebSite`, `Service`, `FAQPage`, `BreadcrumbList`)
  - Master XML Sitemap index referencing 51 dedicated state-city XML sitemaps
  - Comprehensive robots.txt and HTML sitemaps

## Commands

```bash
# Build all 31,020 static pages & XML sitemaps to /dist
npm run build

# Run comprehensive SEO and technical QA linter
npm run lint

# Start production static server
npm run serve
```
